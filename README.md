# Assessify

Assessify is an AI-Assisted Rule-Based Decision Support System for Academic Program Selection of Incoming Freshmen at Gordon College.

## Project Overview

The system helps incoming freshmen choose the most suitable academic program by using:
- structured assessment questions
- rule-based scoring
- match percentages
- personalized explanations

It is developed as a thesis/capstone prototype.

## Main Users

- Incoming Gordon College students
- Admin users
